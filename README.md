# OnlyDate

シンプルな日付表示ウィジェットアプリ

## 概要

OnlyDateは、Androidのホーム画面に日付を表示するシンプルなウィジェットアプリです。カスタマイズ可能な表示オプションと、オプションで気温表示にも対応しています。

## 機能

- **日付表示**
  - 年の表示/非表示切り替え
  - 曜日の表示/非表示切り替え
  - 言語設定（システムデフォルト/英語/日本語）

- **気温表示**（オプション）
  - 現在の気温を表示（デフォルトはオフ）
  - 30分ごとに自動更新
  - 設定変更時にも再取得

- **カスタマイズ**
  - テキストカラーの変更
  - 背景色と透明度の調整

## 使い方

### ウィジェットの追加

1. ホーム画面の空いているスペースを長押し
2. 「ウィジェット」を選択
3. 「OnlyDate」を選択してホーム画面に配置

ウィジェットは設定画面を経由せず、すぐにホーム画面に表示されます。

### 設定の変更

1. ウィジェットをタップして設定画面を開く
2. 各種設定を変更（変更は自動保存されます）
3. 設定画面を閉じる

### 設定項目

- **Text Color**: テキストの色（16進数カラーコード）
- **Background Color**: 背景色（16進数カラーコード）
- **Background Opacity**: 背景の透明度（0-255）
- **Show Year**: 年を表示するかどうか
- **Show Day of Week**: 曜日を表示するかどうか
- **Show Temperature**: 気温を表示するかどうか（デフォルト: オフ）
- **Language**: 曜日の表示言語

## 技術仕様

- **プラットフォーム**: Android
- **言語**: Kotlin
- **更新間隔**: 30分（Androidの最小値）
- **気温API**: カスタムエンドポイント
